# Changelog

## 0.3.0 — 2026-10-29

- Universal Windows/macOS CCX, optional one-click Adobe installer launchers; no external runtimes, npm or Homebrew needed by users.
- Native Mac/Windows download paths, Downloads authorization recovery, private logs, cross-platform import contract tests.
- Skip nested macOS resource forks and unrelated/non-audio archive entries; bound ZIP/audio memory and count, verify output size.
- Do not silently recover unrelated old downloads on panel startup. Explicit retry/manual import remain available.
- Cross-platform anonymous GitHub release notifier, 24-hour cache, no automatic install or restart.
- External browser fallback for website authentication flows the Adobe WebView cannot support.
- Public macOS build is experimental until native validation; Intel/Hackintosh users need a compatible Premiere 26.x, not Mac Premiere 27+.
